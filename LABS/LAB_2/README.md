# LAB_2: Matrices and arrays

## Topic

2D arrays, indexing, and matrix transforms

## Summary

Fill, print, reverse, triangularize, and “snake-fill” NxN matrices using pointer/array arithmetic.

## Tasks

| Task | Title |
|------|-------|
| `task_display_matrix` | Display NxN matrix |
| `task_matrix_as_snake` | Snake-fill matrix |
| `task_matrix_as_snake_array` | Snake-fill matrix (array variant) |
| `task_reverse_matrix` | Reverse matrix |
| `task_upper_triangle` | Upper-triangle fill |

## Build this lab

From repository root:

```bash
make build_LAB_2
```

Artifacts are produced under `build/LABS/LAB_2/…`.

## Clean

```bash
make clean_LAB_2
```
