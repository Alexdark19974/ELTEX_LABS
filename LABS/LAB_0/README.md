# LAB_0: Compilation stages

## Topic

C compilation pipeline (preprocess → compile → assemble → link)

## Summary

Demonstrates how a C file is transformed through intermediate artifacts (.i, .s, .o) before linking into a binary.

## Tasks

| Task | Title |
|------|-------|
| `task_compilation_stages` | Show compilation stages |
