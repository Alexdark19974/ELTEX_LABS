# LAB_7: Static library calculator

## Topic

Static archives (`.a`) and a stack-based calculator

## Summary

Builds `libstack.a` from stack sources and links a RPN-style calculator against the static library.

## Tasks

| Task | Title |
|------|-------|
| `task_static_calc` | Calculator + libstack.a |

## Build this lab

From repository root:

```bash
make build_LAB_7
```

Artifacts are produced under `build/LABS/LAB_7/…`.

## Clean

```bash
make clean_LAB_7
```
