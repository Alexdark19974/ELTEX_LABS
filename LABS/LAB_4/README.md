# LAB_4: Structs and an address book

## Topic

Structure layout/padding and a simple contact ledger

## Summary

Explore struct padding/alignment and build an interactive address-book (ledger) with add/find/remove/display.

## Tasks

| Task | Title |
|------|-------|
| `task_ledger` | Address book (ledger) |
| `task_padding` | Struct padding |

## Build this lab

From repository root:

```bash
make build_LAB_4
```

Artifacts are produced under `build/LABS/LAB_4/…`.

## Clean

```bash
make clean_LAB_4
```
