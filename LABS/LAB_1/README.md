# LAB_1: Bitwise operations

## Topic

Byte-level inspection and modification of integers

## Summary

Practice working with endianness and individual bytes of an `unsigned int` using shifts and masks.

## Tasks

| Task | Title |
|------|-------|
| `task_bitwise_1` | Display bytes of an unsigned int |
| `task_bitwise_2` | Modify a selected byte |

## Build this lab

From repository root:

```bash
make build_LAB_1
```

Artifacts are produced under `build/LABS/LAB_1/…`.

## Clean

```bash
make clean_LAB_1
```
