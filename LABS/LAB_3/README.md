# LAB_3: Pointers

## Topic

Pointers, endianness, and pointer-to-pointer

## Summary

Walk an integer byte-by-byte via pointers, mutate a selected byte, and rebind a pointer through a double pointer.

## Tasks

| Task | Title |
|------|-------|
| `task_ptr_ex1` | Bytes via pointer |
| `task_ptr_ex2` | Change a byte via pointer |
| `task_ptr_ex3` | Double pointer rebinding |

## Build this lab

From repository root:

```bash
make build_LAB_3
```

Artifacts are produced under `build/LABS/LAB_3/…`.

## Clean

```bash
make clean_LAB_3
```
